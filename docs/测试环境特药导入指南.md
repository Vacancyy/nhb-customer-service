# 测试环境特药数据导入指南

## 快速执行

在测试环境服务器上执行：

```bash
# 1. 登录测试环境服务器
ssh user@172.29.4.125

# 2. 进入项目目录
cd /path/to/nhb-customer-service

# 3. 一键执行导入脚本
APP_ENV=stage bash scripts/import-drugs-stage.sh
```

## 分步执行（推荐）

如果一键脚本有问题，可以分步执行：

```bash
# 步骤1：创建特药知识条目（82个）
APP_ENV=stage npx tsx scripts/create-drug-entries.ts

# 步骤2：补充缺失期数的答案
APP_ENV=stage npx tsx scripts/fix-all-drugs-answers.ts

# 步骤3：验证导入结果
APP_ENV=stage npx tsx scripts/check-drugs-coverage.ts
```

## 验证

导入完成后，验证结果：

```bash
# 检查覆盖情况
APP_ENV=stage npx tsx scripts/check-drugs-coverage.ts

# 应显示：
# 各期答案覆盖统计:
#   第3期: 有答案 82, 缺失 0
#   第4期: 有答案 82, 缺失 0
#   第5期: 有答案 82, 缺失 0
#   第6期: 有答案 82, 缺失 0
```

## 测试查询

在测试环境测试特药查询：

```
"伊那利塞片是否属于南京宁惠保特药目录"
"阿可替尼胶囊在特药范围内吗？"
"奥雷巴替尼是特药吗？"
```

应该都能正确返回答案。

## 注意事项

1. 确保测试环境服务器已安装 Node.js 和 npm
2. 确保已拉取最新代码（包含特药导入脚本）
3. 确保 .env.stage 文件存在且配置正确
4. 确保 docs/特药清单.xls 文件存在
